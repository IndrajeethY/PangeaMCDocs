PangeaMC runs in offline mode, so you can change your skin freely using SkinRestorer — no need to own a premium Minecraft account.

## Changing Your Skin

The easiest way is `/skin <username>` — it copies the skin from any Minecraft player name. You can also use a direct image URL if you have a custom skin file.

Your skin updates instantly. No need to relog.

## Commands

| Command | What it does |
| --- | --- |
| `/skin <name>` | Apply a skin by Minecraft username |
| `/skin url <URL>` | Set a skin from a `.png` image URL |
| `/skin update` | Refresh your current skin |
| `/skin clear` | Reset to the default skin |
| `/skins` | Open the skin browser GUI |

<Callout type="info" title="Tip">
  Use `/skins` to browse available skins in a visual menu — it's the easiest way to pick one.
</Callout>
