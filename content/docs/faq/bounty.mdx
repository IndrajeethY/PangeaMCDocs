PangeaMC has a bounty system that adds a layer of PvP excitement. You can place a money or item reward on another player's head — whoever kills them claims the prize.

## How It Works

1. **Place a bounty** — Use `/bounty set <player> <amount>` to put a reward on someone
2. **Hunt them down** — Other players (or you) can track and kill the target
3. **Claim the reward** — Kill the bounty target and the reward is yours

You can place bounties on players even if they're offline. Use `/tracker` for a compass that points toward bounty targets.

## Commands

| Command | What it does |
| --- | --- |
| `/bounty set <player> <amount>` | Place a bounty using money or items |
| `/bounty` | View all active bounties |
| `/bounty check <player>` | Check the bounty on a specific player |
| `/bounty stat` | View your all-time bounty stats |
| `/bounty top` | Leaderboard of top bounty hunters |
| `/tracker` | Get a compass to track bounty targets |

<Callout type="info" title="PvP Tip">
  Bounties make the server more exciting — but watch your back. If someone places a bounty on you, other players will come hunting.
</Callout>
