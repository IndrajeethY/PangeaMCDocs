Guilds let you team up with other players. You get a shared home, private chat, warp points, and your guild shows up on server leaderboards.

## Creating a Guild

Type `/guild create <name>` in-game and you're done — you're now the guild leader. Invite friends with `/guild invite <player>`, and they can join with `/guild join <name>`.

## Essential Commands

| Command | What it does |
| --- | --- |
| `/guild create <name>` | Create your own guild |
| `/guild invite <player>` | Invite someone to join |
| `/guild join <name>` | Accept a guild invitation |
| `/guild leave` | Leave your current guild |
| `/guild kick <player>` | Remove a member |
| `/guild promote <player>` | Promote a member's rank |
| `/guild demote <player>` | Lower a member's rank |
| `/guild disband` | Delete the guild entirely |

## Homes & Warps

Your guild can set a shared home base and multiple warp points for quick travel.

| Command | What it does |
| --- | --- |
| `/guild home` | Teleport to the guild base |
| `/guild sethome` | Set the guild home location |
| `/guild warp create <name>` | Create a named warp point |
| `/guild warp <name>` | Teleport to a warp |
| `/guild warp delete <name>` | Remove a warp |

## Info & Chat

| Command | What it does |
| --- | --- |
| `/guild info` | View guild details and members |
| `/guild list` | See all guilds on the server |
| `/guild chat` | Toggle private guild-only chat |
| `/guild top` | View the guild leaderboard |

<Callout type="info" title="Tips">
  Set your guild home somewhere safe and claimed. Use warps for farms, mines, and grinder spots so your whole team can get around quickly.
</Callout>
